# Lightsaber

A live visuals toolkit for projection mapping, multiple projectors and live VJing.

Build a canvas out of shapes, fill each one with a generated scene, a video,
a webcam or some text, warp it to fit whatever you're projecting onto, and
send the result to as many outputs as you have.

Python backend, browser interface. Runs on one machine for single or dual
output, or drives a second quad-output "render host" over a direct LAN link.

**Pre-release** — scene and canvas JSON may still change between minor
versions.
